t4_inv
------
invert transform

Usage: 	t4_inv <t4file> [inv_t4file]

Examples::

	t4_inv vm11b_anat_ave_to_vm11b_234-3_t4 [vm11b_234-3_to_vm11b_anat_ave_t4]

Options

==	==========================================
-u	suppress (intensity) scale field in output
==	==========================================
